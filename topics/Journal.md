## Assignment 1, "Prototyping: website": 

  Having no prior knowledge of markdown (or any other markup language) I was at first intimidated by the prospect of working on formatting my website in Github, which seemed to me to be hard to navigate during our first 'Hello World' assignment. With that being said, I think that markdown was a good place to start because I found it to be for the most part very intuitive (one # for the first heading, ## for the second, ### for the third, as an example). I found the process of adding a 'path' to my banner image to be very interesting, as well as a good learning example for me. When I first read the instruction, I was picturing the 'path' to the image to be much different than what it actually was. I was imagining something of a storage space for the image to be what the path meant. However, after looking at the *Basic Syntax Guide* and starting to link my image, I realized that the 'path' is the way of telling the system where it will find the image I want to display. Because I have always worked in pre-created templates for things like websites, I've only ever had to 'drag-and-drop' images, and the process of needing to map out where a file is stored was completely new to me. It served as a way to get me thinking about how building instructions worked, which was an important part of this weeks assignment.
